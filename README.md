# Smart Parking Management System (SPMS)

A cloud-native, microservice-based platform for real-time parking space management, built as the final examination assignment for **ITS 1018 - Software Architectures & Design Patterns II** (Graduate Diploma in Software Engineering, IJSE).

SPMS allows drivers to search and reserve parking spaces in real time, lets parking owners manage their spaces dynamically, and handles mock payment transactions with digital receipts all built on a decoupled, scalable microservices architecture.
